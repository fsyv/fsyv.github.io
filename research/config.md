# 研究策略

比例是投入参考，不是成果数量。每天为 C 保留独立选题机会；无合格发现可以为零。两个价值维度分别为低/中/高：研究价值衡量旧问题推进、证据/方法/结论修正，启发价值衡量新视角、未知方法、重要新问题与边界拓展。可靠性另评低/中/高，说明实际阅读范围、可核验性与外推条件；不合并为兴趣相似度分数。

## A：问题深入

从实际 `content/questions/`、笔记和地图中的缺口选题，显式用户任务优先；在重要性相近时优先长期未推进、已有可检验线索的问题。当前只有“如何检验笔记拆分是否改善理解？”演示问题，不推断用户其他私人项目方向。每个重要问题至少每 7 天复评一次；连续两次没有新证据则记录具体障碍与下一次回访，避免重复搜索。

## B：领域动态

当前显式方向为分布式存储与缓存、注意力与大模型推理、概率与网络科学、优化方法，以及知识组织和 Markdown/Obsidian/Hugo 的长期可迁移性与证据质量；以后从新增地图或用户明确反馈扩展。默认窗口为运行前 7 天，补查上次成功监测后的遗漏；记录准确起止时间。新发表、新版本、近期发现旧资料分开。可信来源优先原论文、期刊/会议、研究机构、官方技术文档。没有窗口内重要成果就写零发现，不用旧文献冒充新动态。

## C：开放探索

先选未覆盖的新学科及其自身问题，再考虑与现有知识的联系。轮换池可从信息论、统计物理、因果推断、数值分析、生态学、经济机制设计、科学史等开始，允许继续扩展。连续 3 次不重复同一探索主题；每 4 次至少进入一个此前未覆盖领域。超过 21 天未触及的主题重新评估，不按历史点赞单一排序。

Sol 先筛资料与来源，再由 Astra 深入一个高潜力方向；数学等价、结构类比、经验关联、猜想必须区分，并列出映射失败的部分。当前没有用途不构成排除理由。一次拒绝不取消领域；长期权重调整先生成策略建议供用户审核，C 的机会不被降为零。

## 去重与选择

- 先检索正式笔记 id/标题/正文，再看 `state/sources.md`、近期简报、反馈和未合并研究 PR 中的来源记录。未合并结论仅是候选，不当成正式知识。
- DOI 规范为小写标识；arXiv 以基础 ID 去重、版本单独记录；官方网页去除跟踪参数并保留真实内容版本。预印本与正式论文若同一研究则建立别名，不重复推荐。
- 相同来源仅在有实质新版本、新证据或新问题时回访，写清增量。记录有理由排除的资料和不可访问状态；不把搜索命中数当阅读数。
- 三通道分别产生候选后统一筛选，同一资料不重复计数。高启发、较低直接研究价值的发现可入选；证据不足的联系保存为问题，不包装成结论。
- 最终优先 3–5 项、最多 5 项；不足时不凑数。时间到则交付真实的部分状态，不越过审核/公开检查。日常禁止自动更新主题、工作流或模型配置。

## 运行日与隐私范围

周一至周五 07:30 上海时间触发，周末不自动运行；手动补跑可在任意日期执行。新增领域仅使用通用名称，不公开私人课题、论文状态或候选设计。`content/_private/` 和 `.local/` 不参与公开研究，不用私有文本构造外部检索。
