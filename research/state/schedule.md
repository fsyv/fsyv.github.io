# 原生工作日研究任务

- 名称：个人知识库工作日研究；原生 ID `automation-2`，状态 ACTIVE。
- 时间：周一至周五 **07:30 Asia/Shanghai**，目标 09:30 前交付，不保证完成时间。手动补跑不限工作日。
- 模型：主控和 Sol 角色使用 **gpt-6.1-sol xhigh**，Astra 角色使用 **gpt-6-astra high**。
- 执行：本地项目 fsyv.github.io，每次先读取主目录当前规则及[晨报模板](../templates/daily-digest.md)，再创建或复用唯一活动的跨日研究批次工作树；写作者和审核员使用同一份当前模板。完整任务见[研究提示词](../prompts/daily-research.md)。
- 范围：仅公开知识。`content/_private/` 与 `.local/` 不进入公开研究、简报、PR 或外部检索。
- 交付：任务结果先指出最值得读的发现及理由；PR 开头“今日重点”列出编号、核心结论与推荐理由，随后直接展示完整论证和累计决定清单。本批次往期晨报可在同页展开。按科技写作 pattern 组织句段、机制、公式与证据，阅读索引不替代正文。

任务由 Codex 客户端管理，不手写客户端配置。客户端时区应为 Asia/Shanghai；变更时区时同步调整任务。查看、运行或暂停任务可使用客户端定时任务界面。

电脑必须保持开机、唤醒和 Codex 应用运行，网络、订阅额度与工具权限需可用。已有工作日实际运行记录；每次研究、审核和发布结果按当日回执核验，不以定时配置替代成功。

正式候选从核对过的origin/main开始，跨日复用未合并批次和Draft PR；本地模拟永久禁止推送。流程改造通过独立功能PR审核，知识批次由用户决定合并。

手动补跑：

> 按 research/prompts/daily-research.md 补跑今天研究，复用当日结果和当前待审批次，遵循主目录当前晨报模板：先给今日重点，再在 PR 直接展示完整论证，不自动合并。

私有研究需明确指定“结果仅保存在本地私有区”。迁移电脑时，另行迁移私有知识与备份，并重新关联项目、订阅登录和原生任务。
