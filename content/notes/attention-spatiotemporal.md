## Tokens

普通自注意力并不只处理时间。它读取一组 token；位置代表单词、图像 patch 还是节点，由输入组织及位置表示决定。视频包含 $T$ 帧，每帧分成 $S$ 个空间 patch，得到 $TS$ 个 token。记每个表示为 $x_{t,s}$，由线性投影得到 Q、K、V，并编码帧次序和空间位置。

本文从[缩放点积注意力](attention-qkv.md)推导两种连接方式，以 [TimeSformer §3](../sources/foundations-transformer.md#video)作已发表实例；不把它说成所有时空模型的统一架构。

## Joint

联合时空注意力让每个 $(t,s)$ 查询全部 $(t',s')$：

$$
A_{t,s;t',s'}=\operatorname{softmax}_{t',s'}\left(\frac{q_{t,s}k_{t',s'}^\top}{\sqrt{d_k}}\right),\qquad
o_{t,s}=\sum_{t',s'}A_{t,s;t',s'}v_{t',s'}.
$$

有 $TS$ 个查询，各读取 $TS$ 个位置，所以主要聚合计算为 $O(T^2S^2d)$。空间分辨率或帧数增大都会迅速扩大连接矩阵。这是 token 数量与连接范围的结果，而非“时空”一词本身额外产生某种运算。

## Divided

一种分解方法先在同一空间位置跨帧做时间注意力，再在同一帧内跨空间做注意力。忽略额外分类 token 和投影常数：

$$
C_{\mathrm{time}}=O(ST^2d),\qquad C_{\mathrm{space}}=O(TS^2d),\qquad
C_{\mathrm{divided}}=O((ST^2+TS^2)d).
$$

任意两个时空位置虽未在同一个注意力矩阵里直接相连，信息仍能经两步传播。例如 $(t_1,s_1)$ 先通过时间聚合进入 $(t_2,s_1)$ 的中间表示，再通过空间聚合影响 $(t_2,s_2)$。

连接数量下降依靠结构约束。两次分解计算的 softmax、参数和非线性组合，并不与一次联合注意力严格等价；因此效率和表示能力需要一起评价。TimeSformer 比较的分解模型还具有不同的参数量，不能把其特定实验结果解释成“所有任务中分解都更准确”。

## Assumptions

同一 patch 坐标在不同帧不一定追踪同一个物体，尤其在相机移动时。空间位置、运动与语义关联并非一回事。离线视频分类可读取未来帧，在线预测则需额外因果掩码；结构名称不能代替可见信息的定义。

多头可学习多种关联，但总宽度固定时不会自动消除连接矩阵的二次项。下采样、局部连接和时空分解改变的是不同环节，不能仅把“采用多头”作为复杂度降低理由。

**联系：**[KV 缓存](kv-cache-mechanism.md)依赖因果性；此处的非因果视频注意力不能直接照搬逐帧追加时历史状态永不变化的假设。

## Physical-execution

**2026-10-22 新增 AI 候选解释。** 上文联合/分解改变 token 之间允许的连接，实际 GPU 成本还取决于固定连接怎样铺到计算 tile。[KPage v1 指定正文](../sources/paper-kpage.md)研究后一层：保留稀疏图，将逻辑 block 的有效 K/V 行压成较小页，再跨 block 组合，减少物理填充；它没有证明原分解与联合注意力等价，也不改变图本身的语义。

设每个 128 行逻辑 block 中有 $c_b$ 行有效，Page-16 需要 $p_b=\lceil c_b/16\rceil$ 页。整页与尾页经 page table 直接 gather 到 shared memory，避免额外 HBM 紧凑副本。**AI 布局算例：**一个 Q128 查询块选中三个各有 17 行有效数据的 K/V 块，有用行共 51；整块读取为 384 行，Page-16 各需两页，共 96 行，最终 N128 对齐仍为 128 行，不能将实际 tile 计算称为只处理 51 或 96 行。这里只计算布局容量，没有推出耗时。

Q 有效行不多于 64 时用 64×256，否则用 128×128，两种 tile 面积同为 16,384；仍须保留不同 Q 的邻域。尤其不能只将无效 K 置零：有限 score 仍进入 softmax 分母，须在 row max 前把无效 score 设为负无穷。Backward 按 K/V owner 聚合 reverse-Q 邻域；并集可能创造原图没有的 Q–K 边，因此还需页对 mask 恢复原稀疏图。布局正确与原图正确是同一验证链的两步，[QKV 定义](attention-qkv.md)提供前置。

作者 Table 1 每行固定相同稀疏图/有效行，以 BSA 为基线；8 heads、head dimension 128、BF16，单 GPU/stream，5 次预热后 20 次同步墙钟计时取中位数。四个无 padding 规模的 速度比（BSA 耗时÷KPage 耗时）为 0.94–1.11，几何均值 1.03；四个 3D partial 规模为 1.73–2.95，几何均值 2.29。两组之间图不同，不能称同图消融，更不能把 2.29×当全部注意力或整模型加速。

这些数值只含 kernel，排除图、page table、Q route 与 backward layout 构造；本轮未在 HTML 找到明确实验 GPU 型号，CUDA 13.2 不足以识别硬件。有限 BF16 oracle 对照也不是 bitwise 相同或任务质量保证。增量是把连接数量、填充容量、执行语义与计时分开；动态布局摊销、端到端视频训练和代码仍待核，2026-10-29 复评。其逻辑页是稀疏执行单位，不能直接当作[自回归 KV 缓存](kv-cache-mechanism.md)中的驻留分页与复用收益。
